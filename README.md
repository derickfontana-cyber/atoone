# Relay

Relay is a polished marketing site for an AI automation studio. It explains how intelligent workflows can remove repetitive work, improve capacity, and support sustainable business growth.

## Technology

- TanStack Start and React 19
- TypeScript
- Tailwind CSS 4 with custom responsive styling
- Lucide icons
- Netlify deployment adapter

## Local development

Install dependencies with `pnpm install`, then run `pnpm dev`. The app is available at the local URL shown in the terminal.

Create a production bundle with `pnpm build`.
